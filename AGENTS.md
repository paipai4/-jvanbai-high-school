# Project Instructions

## Git sync rule (mandatory)

Every round of modifications to this project MUST be synced to git before the round is considered finished:

1. `git add -A`
2. `git commit -m "<description of the change>"`
3. `git push` (origin = git@github.com:paipai4/-jvanbai-high-school.git, branch `main`)

Work on a clean tree: after pushing, `git status` must show no uncommitted changes.
